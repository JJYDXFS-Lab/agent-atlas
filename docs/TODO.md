# Deferred refinements

All items below are pending proposals, not implemented changes. They have no scheduled dates. Prefer existing Markdown and Quartz capabilities; assess a small example before expanding scope.

- [ ] **Example-first distinctions.** Try a short definition, an early boundary example and scannable distinctions on Agent and Common ground. Preserve source-specific scope, verified locators and existing URLs; make Agent versus LLM-based implementations and Common ground versus Conversational grounding easier to distinguish. Keep formal detail available below the introductory explanation. Avoid mandatory fields or a larger template.
- [ ] **Clickable numbered sources using native support first.** Compare a small sample using the already-enabled GFM footnotes (`[^1]` with a `[^1]: ...` definition, automatic superscript links and backreferences) against ordinary Markdown links such as `[1, §2.1](#source-1)` with an explicit source anchor to preserve the current bracketed appearance. Plain `[1]` text does not create a link. Preserve one entry per work, article-local numbering and inspected page/section locators; check repeated references and mobile navigation. Quartz also includes a Citations transformer backed by `rehype-citation`, but it is not enabled here: bibliography citekeys such as `[@work]`, CSL style selection and `linkCitations: true` are a separate, optional bibliography workflow. No custom citation parser or bibliography migration is required for this navigation improvement. See the pinned upstream [GFM documentation](https://github.com/jackyzha0/quartz/blob/4923affa7722dfc751f1074348e6dad214fe0c08/docs/plugins/GitHubFlavoredMarkdown.md) and [Citations implementation](https://github.com/jackyzha0/quartz/blob/4923affa7722dfc751f1074348e6dad214fe0c08/quartz/plugins/transformers/citations.ts).
- [ ] **Topic reading routes.** Make the existing topic routes easier to choose: an introductory general-agent route, a POMDP route with conditional probability and finite-sum prerequisites, and a route through related distinctions. Label the order as a reading recommendation; do not imply that every agent is a POMDP or add a separate prerequisite database.
- [ ] **Useful aliases and search.** Add only supported translations or abbreviations, initially in natural searchable prose. The current search indexes title, content and tags; AliasRedirects does not itself add aliases to that index. Verify actual search results in a preview before promising alias search, and do not treat distinct concepts such as common knowledge and common ground as synonyms.
- [ ] **Optional preview improvements.** Make opening paragraphs short and self-contained so existing hover previews are useful. Consider links to specific sections and removal of redundant body titles during later editing. Popovers are already enabled; keep essential explanations accessible without hover.

Follow the [maintenance guide](maintenance.md) when an item is selected for implementation. This list records future editorial and navigation work; it does not change current definitions or citation conventions.
